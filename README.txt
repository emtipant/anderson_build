ALMACENES ANDERSON - PROYECTO FLASK + SQLITE

1. Abrir esta carpeta completa en VS Code.
2. Abrir Terminal > New Terminal.
3. Ejecutar:
   python app.py
4. Abrir en Chrome:
   http://127.0.0.1:5000
5. Administrador:
   http://127.0.0.1:5000/login
   Usuario: propietario
   Contraseña: anderson123

FUNCIONES DEL ADMINISTRADOR
- Cambiar el logo. El mismo logo aparece en tienda, login y administrador.
- Cambiar el texto de la barra superior.
- Agregar, editar y eliminar botones del menú.
- Crear nuevas secciones.
- Editar título, descripción e imagen principal de cada sección.
- Dentro de cada sección, agregar tantos contenidos como se necesite, cada uno con título, descripción e imagen.
  Ejemplo Servicios: Entrega a domicilio, Instalación, Garantía, etc.
  Ejemplo Nosotros: Historia, Misión, Visión, Equipo, etc.
- Editar o eliminar cada contenido de las secciones.
- Agregar/eliminar productos con imagen, precio, stock y categoría.
- Agregar/eliminar imágenes del carrusel principal y de ofertas.
- Las imágenes de carruseles se muestran completas, sin recortarlas.
- Carruseles cambian cada 4 segundos.

IMPORTANTE
- No borrar anderson.db cuando ya exista información guardada.
- Para que la tienda sea accesible desde otros teléfonos/computadoras, después habrá que publicarla en un servidor.
